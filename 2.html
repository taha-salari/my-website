🌐 طراحی وبسایت چیست؟


طراحی وب یعنی ساخت ظاهر و بخش‌های مختلف یک سایت برای نمایش در مرورگر. برای شروع معمولاً

HTML برای ساختار صفحه، CSS برای ظاهر و JavaScript برای رفتارهای تعاملی استفاده می‌شود. یک

سایت خوب باید خوانا، مرتب، سریع و در اندازه‌های مختلف صفحه نمایش قابل استفاده باشد.

HTML


HTML اسکلت سایت است. با آن

عنوان، متن، تصویر، لینک، فرم و

بخش‌های مختلف صفحه را می‌سازیم.

CSS


CSS ظاهر سایت را کنترل می‌کند؛

مثل رنگ، فونت، فاصله، اندازه،

کادر، چیدمان و واکنش‌گرایی.

Java Script


JavaScript باعث می‌شود سایت

تعاملی شود؛ مثلاً با کلیک روی

دکمه چیزی تغییر کند یا یک

محاسبه انجام شود.

🖥️ کامپیوتر

یک کامپیوتر از چند قطعه اصلی تشکیل می‌شود. پردازنده یا CPU عملیات محاسباتی را انجام می‌دهد و

کارت گرافیک یا GPU وظیفه اصلی پردازش تصویر بازی را بر عهده دارد. RAM برای اجرای هم‌زمان بازی و برنامه‌ها

مهم است و SSD سرعت بالا آمدن ویندوز و بازی‌ها را بهتر می‌کند. انتخاب قطعات باید هماهنگ باشد تا یک قطعه قوی توسط قطعه دیگری محدود نشود.

CPU⚡


پردازنده روی اجرای بازی، برنامه‌ها

و کارهای روزمره تأثیر زیادی دارد.

GPU🎨


کارت گرافیک برای رندر کردن تصویر،

کیفیت گرافیکی و FPS بازی بسیار

مهم است.

RAM🧠


رم فضای موقت مورد استفاده

برنامه‌هاست. ظرفیت و سرعت

مناسب آن به اجرای روان‌تر

سیستم کمک می‌کند.

SSD💾


SSD نسبت به هارد دیسک

مکانیکی سرعت خواندن و نوشتن

بالاتری دارد و زمان بارگذاری را

کاهش می‌دهد.

FAN 🌡️


خنک‌ کاری مناسب به حفظ دمای

قطعات و عملکرد پایدار سیستم

کمک می‌کند.

POWER 🔌


منبع تغذیه باید توان و کیفیت

مناسب برای تمام قطعات سیستم

داشته باشد.
